# Programación en C — Curso Intensivo

Bienvenida al curso intensivo de programación en **Lenguaje C**. Este material está diseñado para cubrir los fundamentos esenciales del lenguaje en 10 sesiones de 90 minutos cada una.

---

## ¿Qué aprenderás?

Al finalizar el curso serás capaz de:

- Escribir, compilar y ejecutar programas en C usando **CodeBlocks**
- Comprender la estructura de la memoria y el manejo de datos
- Aplicar estructuras de control: condicionales, ciclos y funciones
- Trabajar con arreglos, cadenas, apuntadores y estructuras
- Leer y escribir archivos desde un programa en C

---

## Cómo usar este material

    Conceptos, palabras reservadas, librerías y funciones explicadas con ejemplos listos para ejecutar en CodeBlocks.

    Ejercicios adicionales para reforzar lo aprendido, presentados al final de cada sesión.

## Herramientas necesarias

- [CodeBlocks](https://www.codeblocks.org/downloads/) con compilador MinGW incluido
- Compilador: **GCC** (incluido en la instalación de CodeBlocks)
- Sistema operativo: Windows / Linux / macOS

---

!!! note "Sobre el lenguaje"
    C es un lenguaje compilado, de propósito general, creado por **Dennis Ritchie** en 1972. Es la base de sistemas operativos, compiladores y software de alto rendimiento. Aprender C te da una comprensión profunda de cómo funciona el hardware y la memoria.
